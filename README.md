# Forecast for No City

A make.fun bounty entry: one funny weather forecast for a city that does not exist. The program writes a single line in the flat voice of an official weather bulletin, then lets the weather itself misbehave — rain falling sideways over the invented town of Plipport — so the sensible-sounding advice quietly escalates into absurdity.

## Run it

```sh
node main.ts
```

This writes the forecast line to `/output/entry.txt`.
